# Clavier et accessibilité

## Raccourcis clavier

| Situation | Touche | Effet |
|---|---|---|
| Aucune fiche ouverte | ← → | Année précédente / suivante |
| Aucune fiche ouverte | Début / Fin | Première / dernière année |
| Fiche d'événement ouverte | ← → | Événement précédent / suivant |
| Fiche ouverte (événement, tribu, commune, aire, province) | Échap | Fermer la fiche |
| Dans la recherche | ↓ ↑, Entrée, Échap | Parcourir, choisir, fermer la liste |
| Sur la carte (après un clic dessus) | flèches, + − | Déplacer et zoomer la carte |

Les flèches ne changent pas l'année quand on tape dans un champ ou quand la carte a le focus.

## Accessibilité

- Les fiches sont de vraies boîtes de dialogue : le focus y entre à l'ouverture, et elles se ferment avec Échap.
- Les boutons de l'en-tête indiquent leur état (activé ou non) aux lecteurs d'écran.
- Les onglets de la recherche sont de vrais boutons radio.
- Les images ont une description (texte alternatif) ; à défaut, le titre de l'événement est utilisé.
- Les points de la carte et les cases des tribus sont accessibles au clavier, avec un libellé (« Tribu de … »).
- Le compteur de la galerie (« 2 / 4 ») est annoncé quand il change.
