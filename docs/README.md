# Documentation de KANAKY · Une histoire en carte

KANAKY est un site interactif qui retrace l'histoire de la Nouvelle-Calédonie sur une carte, année par année, de la culture Lapita à aujourd'hui. Il montre aussi les tribus, les communes, les aires coutumières et les provinces.

Chaque fichier ci-dessous décrit une fonctionnalité : ce que voit le visiteur, comment elle se comporte, et où elle se règle.
